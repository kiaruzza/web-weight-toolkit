# Working glossary

**English** | [Italiano](../GLOSSARIO.md)

| Term | Meaning in the toolkit |
| --- | --- |
| B, kB, KiB | Bytes; 1 kB = 1000 B, 1 KiB = 1024 B. State any unit change |
| Raw bytes | Build file sizes, not observed traffic |
| Transferred | Quantity reported by a network measurement, within the tool's stated boundaries |
| Decoded size | Content after decompression; may exceed transferred bytes |
| Estimated gzip/Brotli | Local file compression, not proof of hosting configuration |
| Local resource | File resolved within the build using the analyzer's rules |
| Other origin | Different scheme, host or port from the final page; not automatically a tracker |
| Cold/warm cache | Resources not reused/reusable from a prior visit; document CDN and service workers too |
| DOM | Document structure built by the browser; node count differs from HTML weight |
| LCP | Metric concerning the arrival of the main viewport content |
| CLS | Metric concerning unexpected layout shifts |
| INP | Interaction responsiveness metric, distinct from TBT |
| TBT | Main-thread blocking metric in a lab test |
| Field data | Aggregated real experiences with their own window and sample |
| Lab | An execution with a configured scenario and conditions |
| W, Wh, kWh | Power, energy, energy; these units are not interchangeable |
| gCO2e | Grams of equivalent emissions; specify model, boundaries and functional unit |
| Indicator | A diagnostic summary within a methodology |
| Baseline | Recorded starting point for comparison |
| Budget | A deliberate threshold that a check can enforce |
| Progressive enhancement | Base functionality available, enhanced where supported |
| WSG / WCAG | Web sustainability/content accessibility guidelines; different scopes |

For browser metrics, use the definitions and documentation linked in the
[performance guide](guide/PERFORMANCE.md), without assuming score equivalence.
