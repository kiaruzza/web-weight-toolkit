# Project origin

**English** | [Italiano](ORIGINE.md)

Extracted and adapted from Chiara Corrado's chiaracorrado.dev source code.
Local source: `chiaracorrado-dev`, the Astro website directory, separate from
the presentation projects.

Reused choices include static builds, semantic layout, skip navigation, colors,
system fonts, print styles and generated-resource measurement tools. Personal
copy, illustrations, translations from the original site, audit results, domains,
FTPS configuration and credentials are not included.

The template simplifies the original layout: the theme follows system
preferences through CSS, without JavaScript bootstrapping or controllers.
New Italian and English example content is provided separately from the original
site's editorial content. The toolkit generalizes checks to every generated HTML page.
Code and documentation are available under the MIT license; see LICENSE.

Further source material includes the JavaScript decision gate, dependency
policy, manual checklists and deployment checks, plus the CDP loading-measurement
script and references from the “Il peso invisibile” presentation.
The toolkit adapts the presentation script to configurable URLs and generalizes
the EcoIndex importer with URL validation and preservation of raw responses.
The new guides connect primary sources with original practical procedures.
